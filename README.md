# Beam

Лаунчер для телевизоров, проекторов и ТВ-приставок на Android, рассчитанный на управление пультом. Интерфейс на русском и английском. Kotlin и Jetpack Compose.

[English version](README.en.md)

## Возможности

- Две раскладки главного экрана: **«Плитки»** и **«Google TV»** (круглые значки приложений и ряды контента).
- Ручной порядок приложений прямо на главном экране в обеих раскладках, фиксированное избранное и экран всех приложений. Меню приложения → «Переместить»: стрелки двигают выбранный значок в его ряду, OK сохраняет, Назад отменяет. Избранные перемещаются внутри своей группы в начале ряда.
- Каналы и «Продолжить просмотр» от установленных приложений: каждый ряд можно включать или скрывать, размещать выше или ниже приложений, менять порядок внутри группы.
- Первоначальная настройка: язык, раскладка с миниатюрами и светлая/тёмная тема. Изменения применяются сразу; повторное открытие — Настройки → «Первоначальная настройка».
- Настройки лаунчера: тема, фоны, включая анимированный XMB, язык, раскладка, звуки.
- Своя картинка на фоне: Настройки → «Выбрать картинку». Сетка миниатюр, предпросмотр под значками и карточками, затемнение 0–80% и применение по подтверждению. Изображение сохраняется в Beam и работает после перезапуска и отключения носителя. Можно вернуться к любому стандартному фону.
- HDMI на главном экране: отдельная плитка для каждого доступного входа, переключатель «Показывать HDMI». Видимость зависит от наличия HDMI-входов и штатного приложения для их открытия; плитка видна только при подключённом источнике и автоматически скрывается при отключении.
- USB-накопители, «Сейчас играет», состояние сети и заряд батареи, если устройство предоставляет эти данные.

Для рядов контента приложение-источник должно публиковать каналы Android TV или записи Watch Next. Beam показывает и упорядочивает этот контент; сама установка приложения не гарантирует появления рядов. История и рекомендации LAMPA проверены на тестовом устройстве; YouTube сейчас не публикует там ряды.

## Совместимость

- **Android 8.0 и новее** (`minSdk 26`), с возможностью установки APK.
- APK поддерживает **armeabi-v7a, arm64-v8a, x86 и x86_64**. На других архитектурах ещё требуется проверка устройства.
- Интерфейс рассчитан на горизонтальный ТВ-экран и пульт со стрелками. Телефоны и планшеты пока не проверены.
- Назначение Beam домашним приложением зависит от прошивки: некоторые производители ограничивают замену лаунчера.
- Каналы, USB, медиастатус и батарея зависят от системных служб, разрешений и оборудования. На обычной прошивке Android ТВ-каналов может не быть.
- Фактически проверенное устройство: XGIMI Play 6, Android 11. Другие модели ещё требуют проверки.

API XGIMI не обязательны. Необязательный адаптер только читает заряд батареи на подходящих прошивках XGIMI; на остальных устройствах используются данные Android. Управления изображением, фокусом, трапецией, HDMI, питанием и таймером сна проектора в Beam нет. Настройки устройства открываются стандартным системным intent; на прошивках XGIMI без такого экрана используется резервное открытие штатных настроек и быстрой панели через системные службы. Это открытие интерфейса производителя, без управления оборудованием из Beam.

## Установка

Скачайте APK из [Releases](https://github.com/tonisaf/beam-launcher/releases) или соберите актуальный исходный код, установите и выберите Beam домашним приложением в настройках Android, если прошивка это позволяет.

**Версии:** v0.4.12 содержит универсальный лаунчер и обновление через GitHub Releases. v0.3 выпущен до этих изменений. Разработка находится в ветке [codex/remove-xgimi](https://github.com/tonisaf/beam-launcher/tree/codex/remove-xgimi); перенос в `main` — [PR #11](https://github.com/tonisaf/beam-launcher/pull/11).

```sh
adb install -r app-release.apk
adb shell cmd package set-home-activity com.home.tiles/.MainActivity
```

Проверьте, что кнопка HOME действительно открывает Beam: успешный ответ ADB сам по себе этого не гарантирует. При первом запуске выберите язык, раскладку и тему. Отдельный диалог **«Beam: не хватает настроек»** объясняет разрешения для дополнительных функций и показывает команды ADB.

[Настройка и необязательные разрешения](docs/installation.md). `tools/restore.ps1` — прежний скрипт для XGIMI, а не универсальный установщик.

## Обновления

Beam проверяет последний стабильный [GitHub Release](https://github.com/tonisaf/beam-launcher/releases/latest) при открытии домашнего экрана, не чаще раза в сутки. В Настройки → «Обновление Beam» можно проверить вручную или отключить автоматическую проверку. «Позже» отключает автоматическое предложение этой версии; ручная проверка остаётся доступной. После ошибки следующая автоматическая попытка возможна через час. Тихой фоновой установки нет.

Выберите «Скачать обновление», затем «Установить». Beam проверяет размер и SHA-256 из GitHub, имя пакета, совпадение подписи с установленным приложением и увеличение versionCode. Android запросит подтверждение установки. Если требуется, разрешите установку APK из Beam и нажмите «Установить» ещё раз. Незавершённая загрузка при закрытии окна удаляется; можно открыть окно и повторить.

Для публикации используются стабильные числовые теги (`v0.4`, `v0.5`, `v1.0.1`) и файл `app-release.apk`. Сохраняйте релизный ключ подписи и увеличивайте versionName и versionCode. У файла должен быть GitHub digest `sha256:`; без него APK отклоняется. Приложение не содержит токен GitHub и получает только публичные релизы. [Порядок выпуска](docs/releases.md).

## Сборка

Нужны JDK 17 и Android SDK (путь в `ANDROID_HOME` или `local.properties`).

```sh
./gradlew :app:assembleRelease
```

APK лаунчера появится в `app/build/outputs/apk/release/`. Отдельная задача `:stub:assembleRelease` собирает прежние помощники кнопок пульта для отдельных прошивок; при обычной установке они не нужны.

### Подпись

Релизы подписаны постоянным ключом, он лежит вне репозитория. Благодаря этому новую версию можно
ставить поверх старой (`adb install -r`, настройки сохраняются). Gradle берёт ключ из
`~/.beam/release.properties` (или из файла, путь к которому в `BEAM_RELEASE_PROPS`):

```properties
storeFile=C:/Users/you/.beam/beam-release.jks
storePassword=...
keyAlias=beam
keyPassword=...
```

Ключ создаётся один раз: `keytool -genkeypair -alias beam -keyalg RSA -keysize 4096 -validity 36500
-keystore beam-release.jks`. Храните копию: потерянный ключ значит, что у всех придётся удалить Beam и
поставить заново. Без этого файла (например, в CI) сборка подписывается debug-ключом компьютера:
она ставится, но не обновит Beam, подписанный настоящим ключом, и наоборот. Отпечаток SHA-256
сертификата релизов: `B0:A3:37:70:07:0C:3C:84:00:29:E1:D4:B3:4F:F3:CF:05:F0:A3:4B:97:41:7D:62:22:38:3E:95:9E:8C:20:F9`.


## Прежняя интеграция XGIMI

Управление проектором сохранено в [архивной ветке](https://github.com/tonisaf/beam-launcher/tree/codex/archive-xgimi-2026-10-13). [Исследование прошивки](docs/xgimi-firmware.md), `tools/restore.ps1`, `skin/` и `russifier/` относятся к прежней интеграции и не описывают возможности текущего универсального лаунчера.
