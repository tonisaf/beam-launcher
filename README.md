# Beam

Лаунчер для телевизоров, проекторов и ТВ-приставок на Android, рассчитанный на управление пультом. Интерфейс на русском и английском. Kotlin и Jetpack Compose.

[English version](README.en.md)

## Возможности

- Две раскладки главного экрана: **«Плитки»** и **«Голдовая»** (круглые значки приложений и ряды контента).
- Ручной порядок приложений пультом, фиксированное избранное и экран всех приложений. Меню приложения → «Переместить»: стрелки перемещают, OK сохраняет, Назад отменяет.
- Каналы и «Продолжить просмотр» от установленных приложений: каждый ряд можно включать или скрывать, размещать выше или ниже приложений, менять порядок внутри группы.
- Первоначальная настройка: язык, раскладка с миниатюрами и светлая/тёмная тема. Изменения применяются сразу; повторное открытие — Настройки → «Первоначальная настройка».
- Настройки лаунчера: тема, фоны, включая анимированный XMB, язык, раскладка, звуки и голос.
- USB-накопители, «Сейчас играет», состояние сети и заряд батареи, если устройство предоставляет эти данные.
- Необязательный офлайн голосовой поиск Vosk, голосовой ввод в приложениях, команды запуска приложений и управления воспроизведением.

Для рядов контента приложение-источник должно публиковать каналы Android TV или записи Watch Next. Beam показывает и упорядочивает этот контент; сама установка приложения не гарантирует появления рядов. История и рекомендации LAMPA проверены на тестовом устройстве; YouTube сейчас не публикует там ряды.

## Совместимость

- **Android 8.0 и новее** (`minSdk 26`), с возможностью установки APK.
- В текущем APK нативные библиотеки только для **armeabi-v7a**. Система должна поддерживать 32-битные ARM-приложения; устройства только с ARM64 и устройства x86 этой сборкой не поддерживаются.
- Интерфейс рассчитан на горизонтальный ТВ-экран и пульт со стрелками. Телефоны и планшеты пока не проверены.
- Назначение Beam домашним приложением зависит от прошивки: некоторые производители ограничивают замену лаунчера.
- Каналы, USB, медиастатус, голосовая кнопка и батарея зависят от системных служб, разрешений и оборудования. На обычной прошивке Android ТВ-каналов может не быть.
- Фактически проверенное устройство: XGIMI Play 6, Android 11. Другие модели ещё требуют проверки.

API XGIMI не обязательны. Необязательный адаптер только читает заряд батареи на подходящих прошивках XGIMI; на остальных устройствах используются данные Android. Управления изображением, фокусом, трапецией, HDMI, питанием и таймером сна проектора в Beam нет. Настройки Android открываются стандартным системным intent.

## Установка

Скачайте APK из [Releases](https://github.com/tonisaf/beam-launcher/releases) или соберите актуальный исходный код, установите и выберите Beam домашним приложением в настройках Android, если прошивка это позволяет.

**Исходный код и опубликованный релиз:** изменения универсального лаунчера сейчас находятся в ветке [codex/remove-xgimi](https://github.com/tonisaf/beam-launcher/tree/codex/remove-xgimi). Опубликованный релиз **v0.3 от 2026-10-05** выпущен до этих изменений. Этот README описывает указанную ветку, а не старый APK релиза; для распространения изменений нужен новый релиз.

```sh
adb install -r app-release.apk
adb shell cmd package set-home-activity com.home.tiles/.MainActivity
```

Проверьте, что кнопка HOME действительно открывает Beam: успешный ответ ADB сам по себе этого не гарантирует. При первом запуске выберите язык, раскладку и тему. Отдельный диалог **«Beam: не хватает настроек»** объясняет разрешения для дополнительных функций и показывает команды ADB. Голосовая модель устанавливается отдельно.

[Настройка и необязательные разрешения](docs/installation.md). `tools/restore.ps1` — прежний скрипт для XGIMI, а не универсальный установщик.

### Голосовая модель

Модель Vosk (~45 МБ) не входит в APK и сама не скачивается: без неё голосовое распознавание недоступно. Поставьте её по adb один раз (нужно разрешение микрофона, см. инструкцию настройки):

```sh
# устройство скачивает модель сам (только https; для проверки добавьте --es voice_sha256 <SHA-256 архива>):
adb shell am broadcast -n com.home.tiles/.AdbCommandReceiver \
    --es voice_url https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip
# или залейте файл с компьютера (см. `VoiceModelProvider` в `Voice.kt`):
adb exec-in "content write --uri content://com.home.tiles.voicemodel/model.zip" < vosk-model-small-ru-0.22.zip
adb shell am broadcast -n com.home.tiles/.AdbCommandReceiver --ez voice_install true
```

Голосовые команды открывают SmartTube, Spotify и Jellyfin (любую из известных сборок, какая
установлена; не установленные не распознаются). Свои приложения добавляются по adb:

```sh
adb shell am broadcast -n com.home.tiles/.AdbCommandReceiver \
    --es voice_app "Kodi|org.xbmc.kodi|коди;открой коди"   # имя | пакеты через запятую | фразы через ;
adb shell am broadcast -n com.home.tiles/.AdbCommandReceiver --ez voice_apps true          # список добавленных
adb shell am broadcast -n com.home.tiles/.AdbCommandReceiver --es voice_app_remove Kodi    # убрать
```

Модель Vosk русская, поэтому фразы пишите по-русски (так, как их произносят). Язык интерфейса
на голос не влияет: команды всегда русские.

Beam отвечает и на стандартные запросы распознавания речи от других приложений
(`RECOGNIZE_SPEECH`, `RecognitionService`). Поэтому любое установленное приложение может получить
расшифровку того, что вы говорите в микрофон пульта, пока вы держите голосовую кнопку, даже если у
самого приложения нет права на микрофон: так устроен этот механизм Android. Без зажатой кнопки
запись не идёт. Если это неприемлемо, не назначайте Beam распознавателем и не ставьте модель.

Проверка: `--ez voice_status true`. Чтобы кнопки микрофона в других приложениях (например, SmartTube)
тоже использовали Beam, назначьте его системным распознавателем (по желанию):
`adb shell settings put secure voice_recognition_service com.home.tiles/com.home.tiles.VoskRecognitionService`.


## Сборка

Нужны JDK 17 и Android SDK (путь в `ANDROID_HOME` или `local.properties`).

```sh
./gradlew :app:assembleRelease
```

APK лаунчера появится в `app/build/outputs/apk/release/`. Отдельная задача `:stub:assembleRelease` собирает прежние помощники кнопок пульта для отдельных прошивок; при обычной установке они не нужны.

### Подпись

Релизы подписаны постоянным ключом, он лежит вне репозитория. Благодаря этому новую версию можно
ставить поверх старой (`adb install -r`, настройки сохраняются). Gradle берёт ключ из
`~/.beam/release.properties` (или из файла, путь к которому в `BEAM_RELEASE_PROPS`):

```properties
storeFile=C:/Users/you/.beam/beam-release.jks
storePassword=...
keyAlias=beam
keyPassword=...
```

Ключ создаётся один раз: `keytool -genkeypair -alias beam -keyalg RSA -keysize 4096 -validity 36500
-keystore beam-release.jks`. Храните копию: потерянный ключ значит, что у всех придётся удалить Beam и
поставить заново. Без этого файла (например, в CI) сборка подписывается debug-ключом компьютера:
она ставится, но не обновит Beam, подписанный настоящим ключом, и наоборот. Отпечаток SHA-256
сертификата релизов: `B0:A3:37:70:07:0C:3C:84:00:29:E1:D4:B3:4F:F3:CF:05:F0:A3:4B:97:41:7D:62:22:38:3E:95:9E:8C:20:F9`.
